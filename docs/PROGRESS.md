# Журнал разработки «После героя»

Накопительный журнал прогресса. Одна запись на микроэтап: что сделано,
как проверить. Пополняется в том же коммите, что и микроэтап.

## M0 — подготовка

### M0.1 — инициализация проекта

- Установлен Go 1.27.1 (`brew install go`).
- Инициализирован git-репозиторий и модуль `afterhero`.
- `.gitignore` для бинарников и артефактов Go.

Проверка: `go version` → go1.27.1 darwin/arm64.

### M0.2 — спецификация и процесс

- `DESIGN.md` — финальная спецификация MVP с тремя поправками,
  принятыми при ревью: `turn++` — последняя операция `Step`; страх — чистая
  производная от памяти без хранимого поля; выбор тела кодируется событием
  `BodyChosen` (не расходует ход, но воспроизводится в replay).
- `docs/PROGRESS.md` — этот журнал.
- Процесс: микроэтап → зелёные `go test ./...` и `go vet ./...` → запись сюда →
  осмысленный коммит.

## M1 — чистое ядро симуляции

### M1.1 — идентификаторы и стабильные enum'ы

- `internal/sim/id.go` — `EntityID`, `ItemID`, `Seq` (все с 1, ноль = «участника нет»,
  переиспользование ID запрещено), `Vec2` с `Add` и `Manhattan`.
- `internal/sim/enums.go` — все сериализуемые enum'ы с явными стабильными
  значениями: клетки, виды существ (= фракции в MVP), действия, события (15 видов),
  предметы, причины смерти/урона, состояния целей мести, исходы кампании.
  Схема событий: `SchemaVersion = 1`.
- `internal/sim/enums_test.go` — `TestEnumStability` фиксирует каждое числовое
  значение (переупорядочивание констант = громкий провал, а не тихая порча replay);
  `TestVec2` — арифметика координат.

Проверка: `go test ./...` и `go vet ./...` — зелёные.
